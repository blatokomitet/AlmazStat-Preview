# AlmazStat Preview

Статическое превью интерфейса AlmazStat для просмотра прямо через GitHub Pages.

## Preview

После включения GitHub Pages адрес:

https://blatokomitet.github.io/AlmazStat-Preview/

## Что здесь

- `index.html` — автономное мобильное превью без API-ключей и серверных зависимостей.
- `.github/workflows/pages.yml` — автоматический деплой GitHub Pages при каждом push в `main`.

Основной рабочий backend остаётся в отдельном репозитории `AlmazStat`. Этот репозиторий нужен для безопасного визуального превью.
